# Notifications

The board tells you when something needs you, so you don't have to keep it open.

## What you're told about

- A T3 Code thread linked to a task is **waiting for input or approval**.
- A linked pull request's **checks start failing**, or a reviewer **requests changes**.
- A **local review round finishes**, with what it found.
- An **Autopilot run fails** or gives up.

Each change is announced once. A pull request or thread you link is not announced for the state it already
has; only for what changes after.

## The inbox

The bell in the board's header shows how many are unread. Click it to see them, newest first. Click one to
open its task and mark it read, filter by type, or use **Mark all read**. Notifications are kept for 30 days.

## Pop-ups

In the desktop app, a pop-up appears when you're not looking at the board; clicking it brings the window
forward and opens the task. The taskbar button shows the unread count (a red circle, `9+` past nine), and the
tray icon gets a red dot while anything is unread.

In a browser, open **Settings → Notifications** and choose **Allow in this browser**. Pop-ups then come from
one tab, and only while you're not looking at the board. The tab's icon shows the count too.

## Settings

**Settings → Notifications** has a switch for each type. A type that is off isn't recorded at all, in the inbox
or as a pop-up. **Mute during quiet hours** keeps pop-ups quiet while Autopilot's quiet hours are on; the
notifications still wait in the inbox.
